# RoadFix: AI Pothole Detection and Road Maintenance Showcase

RoadFix is an educational project showcase demonstrating an AI-assisted pothole detection and road maintenance workflow. It brings together road image review, issue reporting, GIS mapping, repair coordination, and road condition analytics.

**Explore the live project:** [RoadFix road maintenance showcase](https://pothole-management-system-showcase.onrender.com/)

This is a project demonstration, not an official municipal reporting or emergency service.
